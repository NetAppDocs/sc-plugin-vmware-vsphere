= What's new in the SnapCenter Plug-in for VMware vSphere 6.2.1

:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
SnapCenter Plug-in for VMware vSphere 6.2.1 is a maintenance release. It updates the third-party software shipped with the appliance and includes fixes for issues found since the SnapCenter Plug-in for VMware vSphere 6.2 release.

== Updated components

[options="header"]
|===
| Component | SnapCenter Plug-in for VMware vSphere 6.2.1
| Java runtime  | OpenJDK 21.0.12 
| .NET runtime | .NET 10.0.11
| Appliance operating system  | Debian 13 
| Messaging, security, and user 
interface libraries  | Updated with the release
|===


== Fixed issues
It is good practice to review the known issues fixed in a release before upgrading to it.

* Renaming a source ONTAP volume no longer leaves secondary backups stuck on the old name, or displaying entries that are no longer valid. 

* Cleanup of secondary backups no longer waits for hours on one volume it cannot reach. Other volumes continue to be processed. 

* Restoring a VM to a different location keeps the VM storage policy, so the restore is no longer rejected for VMs that use a non-default policy. 

* Cloud-managed ONTAP on Oracle Cloud can be added as a storage system. 

* Browsing a backup to restore individual files no longer fails. 

* A new appliance deployment no longer fails to complete during first-time setup. 

* The maintenance console no longer reports that VMware Tools are missing. 

* The management interface loads and sign-in completes. 

* The Backups and Resource Groups configuration pages load. 

* The schedules page no longer fails to load when one schedule record is incomplete. 

* VM restore no longer fails because the list of destination hosts was not loaded.

* Attaching or restoring a virtual disk no longer fails when vCenter briefly reports the datastore as unavailable. 

* When a user is not allowed to delete a resource group, the permission message is shown. 

* Security issue around storage password capturing is fixed. 

* Support log bundles include the list of configured storage systems. 

* On-screen text and translations were updated.
