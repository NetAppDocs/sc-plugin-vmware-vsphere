= What's new in the SnapCenter Plug-in for VMware vSphere 6.2.1

:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
SnapCenter Plug-in for VMware vSphere 6.2.1 is a maintenance release. It updates the third-party software shipped with the appliance and includes fixes for issues found since the SnapCenter Plug-in for VMware vSphere 6.2 release.

== Updated components

[options="header"]
|===
| Component | SnapCenter Plug-in for VMware vSphere 6.2.1
| Java runtime  | OpenJDK 21.0.12 
| .NET runtime | .NET 10.0.11
| Appliance operating system  | Debian 13
|===


== Fixed issues
It is good practice to review the known issues fixed in a release before upgrading to it.

* VMDP-7072: Cloud-managed ONTAP on Oracle Cloud can be added as a storage system. 

* VMDP-7052: Restoring a VM to a different location keeps the VM storage policy, so the restore is no longer rejected for VMs that use a non-default policy. 

* VMDP-7027: Support log bundles include the list of configured storage systems. 

* VMDP-6987: Attaching or restoring a virtual disk no longer fails when vCenter briefly reports the datastore as unavailable. 

* VMDP-6965: The schedules page no longer fails to load when one schedule record is incomplete. 

* VMDP-6952: When a user is not allowed to delete a resource group, the permission message is shown. 

* VMDP-6939: The maintenance console no longer reports that VMware Tools are missing. 

* VMDP-6935: Browsing a backup to restore individual files no longer fails. 

* VMDP-6933: A new appliance deployment no longer fails to complete during first-time setup. 

* VMDP-6931: Cleanup of secondary backups no longer waits for hours on one volume it cannot reach. Other volumes continue to be processed. 

* VMDP-6817: Renaming a source ONTAP volume no longer leaves secondary backups stuck on the old name, or displaying entries that are no longer valid.
